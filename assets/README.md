# Plugin icon

`icon.svg` is the editable source for the LMM for VS Code icon. `icon.png` is the
raster export used by the VS Code extension manifest and Marketplace.

The four folded-ribbon paths are the project-owned vector adaptation of the LMM
master, copied unchanged from `api.lmm.best-microservices/.github/assets/logo-geometry.json`
(schema `lmm-api.logo-geometry/2`). The original master is authoritative; the SVG
is an editable approximation. The editor-window cue is original geometry and does
not use the VS Code or GitHub Copilot trademarks.

The SVG contains no external resources, fonts, text rendering, or scripts.
